**Agent note:** For non-trivial docs (PRD, OKRs, North Star, Roadmap, Strategy, Opportunity Assessment, JTBD, Personas, Segment definition, Product-Market Fit, Problem-Solution Space), you **must ask** 2–3 preflight prompts from [system/coaching/prompts.md](../system/coaching/prompts.md) before helping fill in the template. Required prompts:
- "Why this, why now?"
- "What do you already know vs. what are you guessing?"
- "Who is this for?" (if not clear from context)

For lighter docs (user stories, meeting agenda, newsletter, sprint summary, backlog item, decision record, stakeholder avatar, 10 Things Workshop, course design), preflight is optional  but **"optional" is not the same as "skip"**. If the request has meaningful scoping decisions embedded (e.g. user stories for a live pilot where persona priority, scope boundaries, or acceptance criteria are non-obvious), ask 2-3 targeted questions before writing. Having repo context is not a substitute for the user's thinking on those decisions.

For non-trivial docs, also ask whether the user has added relevant company/initiative/research context, or if you should reference [1-Context/](../1-Context/README.md), [4-Research/](../4-Research/README.md), or [3-Work/](../3-Work/README.md).

**Reminder:** For non-trivial docs (strategy, PRD, big opportunity), braindump first: [README.md](../system/coaching/README.md).
