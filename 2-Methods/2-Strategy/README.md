# 2-Strategy — Methods Overview

This domain contains the core strategy methods you use to set direction, translate it into plans, and specify work.

## Before Using Any Strategy Framework

⚠️ **Don't jump straight to strategy templates.**

### 1. Read the Golden Rule

**See:** [braindump.md](../../system/coaching/braindump.md) (coaching)

### 2. Braindump First (20-30 min)

**Use the prompts:** [system/coaching/prompts.md](../../system/coaching/prompts.md) — [Mid — direction exists, deciding on approach](../../system/coaching/prompts.md#before-a-product-strategy-session).
**Or start from the entry point:** [README.md](../../system/coaching/README.md) (simple prompt for a product-thinking chat).

Quick start from that section:
- What's the single most important assumption you're making right now?
- What does success look like in 6 months → How exactly would you measure it?
- Who loses if this succeeds → What are you trading off?
- What's the minimum you'd ship to test this → What are you over-building?

**Strategy frameworks organize direction—they don't create vision.**

### 3. Then Use Strategy Frameworks

After your braindump, use the frameworks below to structure your strategy.

## Strategic Frameworks

## How this is organized

- **Strategic Foundations** (`1-Strategic-Foundations/`)  
  Long-term direction: Strategy Blocks (process), Playing to Win (choices), Good Strategy/Bad Strategy (evaluation), plus the [When to Use Which](1-Strategic-Foundations/README.md#when-to-use-which) section in the Strategic Foundations README.

- **Strategic Execution** (`2-Strategic-Execution/`)  
  Turning direction into action: OKRs (goals), Roadmap (time-phased plan), North Star (measurement), Prioritization (what to do first, with RICE/ICE, MoSCoW, Kano, decision tree).

## Typical flow

Strategic Foundations → OKRs → Roadmap → North Star → Prioritization → (PRDs/Personas/Delivery)
