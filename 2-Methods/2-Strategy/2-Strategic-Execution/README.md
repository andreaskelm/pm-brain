# Strategic execution

Direction is set; you're turning it into goals, plans, metrics, and priorities.

**Agents:** load the matching skill first ([0-index.md](../../0-index.md)) — `okr`, `roadmap`, `north-star`, `prioritize`. Use the framework folders below for full guides, templates, and evaluations when you need depth beyond the skill.

| Need | Skill | Framework folder |
|------|--------|------------------|
| Quarterly outcomes | `okr` | [1-OKR/](1-OKR/) |
| Now / Next / Later plan | `roadmap` | [2-Roadmap/](2-Roadmap/) |
| North Star + input metrics | `north-star` | [3-North-Star/](3-North-Star/) |
| What to build first | `prioritize` | [4-Prioritization/](4-Prioritization/) |

## When to use

- You have strategic pillars/choices defined and need to execute.
- You're planning a quarter/half and need goals, plan, and sequencing.
- You need a measurable north star to track value delivered.
- You must decide what to build first (or what to cut).

## Typical flow

1. Start from pillars/choices (see [Strategic Foundations](../1-Strategic-Foundations/)).
2. Convert to outcomes with **OKRs**.
3. Sequence initiatives with a **roadmap**.
4. Align on value with a **north star** metric/tree.
5. Choose what to do first with **prioritization**.

**Prioritization decision help:** [4-Prioritization/1-decision-tree.md](4-Prioritization/1-decision-tree.md)
