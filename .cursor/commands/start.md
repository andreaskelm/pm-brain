# Start a new initiative

Launch a new initiative end-to-end. Run braindump and bias check first (system/coaching/braindump.md: think before structure), then walk through phases: early thinking → opportunity assessment → strategy alignment → discovery → PRD/roadmap → execution and communication.

**Reference:** @3-Work/1-Initiative-Codename/ (structure), @2-Methods/3-Discovery/4-Opportunity-Assessment (early thinking), system/coaching/braindump.md (braindump first). Use @2-Methods/ for each phase's frameworks.

**Phases (high level):** 0 Braindump + bias check → 1 Foundations (mental models, pre-mortem) → 2 Early thinking (opportunity assessment, 3-Work folder) → 3 Strategy alignment → 4 Discovery (research, JTBD, validation) → 5 Specify & plan (PRD, personas, metrics, roadmap) → 6 Execution & communication (daily/weekly rhythm) → 7 Validate & iterate.

**Output:** Initiative name and status, completed phases checklist, next actions (immediate + upcoming), files to create/update, watch items.

**Related:** /bias before major decisions; /focus for priority; /day and /week for rhythm; /navigate if stuck.
