# Navigate to the right framework

From the user's situation, recommend the right phase and framework(s). Ask 1–2 diagnostic questions if needed, then point to the right path in `2-Methods/`.

**Reference:** [0-template-finder.md](../../2-Methods/0-template-finder.md) and the flow: **1-Foundations → 2-Strategy → 3-Discovery → 4-Execution → 5-Communication**.

**Quick routing:**
- Don't know what to build / need customers → **3-Discovery** (research, JTBD, opportunity assessment)
- Need direction / strategy → **2-Strategy** (foundations, OKRs, roadmap, prioritization)
- Ready to build / specify → **4-Execution** (PRD, personas, metrics); use `/day` and `/week` for rhythm
- Align stakeholders / communication → **5-Communication** (newsletter, agendas, stakeholder management)
- Stuck / overwhelmed → **1-Foundations** (mental models, bias, self-reflection); use `/bias`, `/focus`
- Starting new initiative → `/start`
- Too many priorities → `2-Strategy/2-Strategic-Execution/4-Prioritization/`; use `/focus`

If the user hasn't braindumped yet, point to [system/coaching/README.md](../../system/coaching/README.md) first.
