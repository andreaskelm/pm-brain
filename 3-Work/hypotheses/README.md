# Hypotheses

Bets you are testing that are too small for an initiative folder. One file per belief: `<slug>.md`.

A hypothesis has evidence for and against, a confidence of High / Med / Low, the cheapest test, and a decision trigger. It does not have a PRD or a roadmap.

**Open or update one through the `capture` skill, after the braindump floor.** The page shape lives in `.claude/skills/capture/references/template.md`. This folder does not keep a schema or an example slug. The first real file is created in a session, once you have named the assumption that decides it, separated know from guess, named a risk, and said the uncomfortable part.

An observation does not become a file here. Park it in `4-Research/` or on today's note in [../signals/](../signals/).

## When it grows up

Move the bet into `3-Work/[initiative]/` when it needs an opportunity assessment, its own research folder, or a PRD. Leave a one-line pointer in the hypothesis file so the evidence trail still resolves.

## When it is a scored call

A decision trigger firing is an offer, not a write. A row in `5-Growth/decisions.md` happens when you state a confidence percent and confirm it.
