# 99-Archive — Completed or Paused Initiatives

Move initiative folders here when work is done, paused indefinitely, or superseded. Keeps `3-Work/` focused on active bets.

**When archiving:** Preserve the folder as-is (README, decisions, final artifacts). Add a one-line note at the top of the initiative README with archive date and reason.

**Agent rule:** Do not treat archived initiatives as active context unless the user explicitly references them.

See [docs/principles.md](../../docs/principles.md) § Privacy & Health.
