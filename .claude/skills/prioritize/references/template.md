# Prioritization Record

One per major prioritization session (quarterly planning, a big re-plan, a stakeholder escalation). Keep it to a page. The trade-offs section is the part people come back for.

```markdown
# Prioritization — [Scope] — [Date]

**Decision owner:** [one name]
**Method:** [RICE / ICE / Impact–Effort / MoSCoW / Kano] — why this one: [one line]
**Optimizing for:** [the outcome or OKR this serves]
**Capacity:** [team, timebox]   **Next review:** [date]
**Disclaimer:** Priorities reflect current strategy and will shift as we learn.

## Top items

| Rank | Item | Score | Key assumption behind the score | Why now |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

## Trade-offs (what we're NOT doing to do this)
- To do [A], we're not doing [B] because [reason]
- [C] is delayed until [when] because [reason]

## Not doing (this time)
| Item | Requested by | Why not now | What would change our mind |
|---|---|---|---|
| | | | |

## Changes since last time
- [Item] moved #15 → #3 because [new evidence]

## Stakeholder calls
- [Person] asked for [item]; scored [x]; placed at [rank]; outcome: [agreed / escalated / alternative offered]

## Reopen triggers
- [Signal that would force an early re-prioritization]
```

## Backlog item (when an item needs more than a title)

```markdown
**Item:** [specific, e.g. "Redesign checkout to reduce abandonment", not "Better UX"]
**Type:** Initiative | Feature | Improvement | Tech debt | Bug
**Supports:** [OKR / goal]   **Requested by:** [name]
**Problem / evidence:** [what we know, and the evidence tier]
**Score:** [method + numbers + rationale]
**Effort:** [S/M/L/XL or person-months]   **Dependencies:** [ ]
**Status:** Backlog | Ready | In progress | Done
```
