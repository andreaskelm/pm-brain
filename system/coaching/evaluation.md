# When Stuck — Decision Diagnostic

Use after a braindump that isn't moving. Exit criteria for leaving braindump live in [braindump.md](braindump.md). Session sequence: [README.md](README.md). More prompts: [prompts.md](prompts.md).

Name the block type, then act. Don't try to solve every block at once.

## Step 1: Name the block

| Block | Signals | Immediate action |
|-------|---------|-----------------|
| **Information gap** | "I don't have enough data" / "I don't know the user need" | Stop deciding. Run one interview or spike. Set a 48h deadline. |
| **Uncertainty / risk** | "Stakes too high" / "Can't predict outcome" | Name the reversibility. Define the smallest test. Set a decision date anyway. |
| **Complexity** | "Too many variables" / "Every option has tradeoffs" | Pick the single highest-stakes tradeoff. Ignore the rest for now. |
| **Politics** | "I know what to do but can't get buy-in" | Separate the decision from the alignment problem. Solve sequentially. |

## Step 2: Move

- Write down your current best guess, even if it feels wrong.
- Name the single assumption that, if true, would make this easy.
- Set a decision deadline — imperfect decisions beat no decision.
- Ask: "What's the cost of deciding wrong vs. not deciding?"

## If still stuck

Use the `/unstuck` command or bring it to a colleague. Sometimes the block is emotional, not analytical.
