# When Stuck — Decision Diagnostic

Use after a braindump that isn't moving. Exit criteria for leaving braindump live in [braindump.md](braindump.md). Session sequence: [README.md](README.md). More prompts: [prompts.md](prompts.md).

Name the block type, then act. Don't try to solve every block at once.

## Step 1: Name the block

| Block | Signals | Immediate action |
|-------|---------|-----------------|
| **Information gap** | "I don't have enough data" / "I don't know the user need" | Stop deciding. Run one interview or spike. Set a 48h deadline. |
| **Uncertainty / risk** | "Stakes too high" / "Can't predict outcome" | Name the reversibility. Define the smallest test. Set a decision date anyway. |
| **Complexity** | "Too many variables" / "Every option has tradeoffs" | Pick the single highest-stakes tradeoff. Ignore the rest for now. |
| **Politics** | "I know what to do but can't get buy-in" | Separate the decision from the alignment problem. Solve sequentially. |
| **Internal** | "I know the answer but can't act" / procrastinating on analysis | Name what you're avoiding. See internal blocks below. |

## Reframe before you unblock

Sometimes the block isn't missing data — it's the wrong frame. Check these before picking a technique.

### Strategy disguised as prioritization

- [ ] People agree on the data but disagree on what it means
- [ ] Two paths both seem reasonable and the difference comes down to values or vision
- [ ] The decision keeps restarting even after being "resolved"
- [ ] You've realized the real question isn't the one you started with

**If checked:** This isn't a prioritization call — it's a strategy alignment problem. Name the values conflict explicitly before scoring options.

### Taste / conviction gap

- [ ] You know what's analytically correct but it doesn't feel right
- [ ] You're missing a strong POV and waiting for data to tell you what to think
- [ ] All the options feel mediocre — you sense there's a better framing you haven't found
- [ ] You'd be embarrassed if this decision leaked outside the team

**If checked:** Stop gathering more data. Write your gut call in one sentence, then stress-test it: "What would be the first signal I'm wrong?"

### Internal blocks

- [ ] I know what to do but don't want to do it
- [ ] I'm waiting for permission I don't need
- [ ] I'm procrastinating by doing more analysis
- [ ] I'm emotionally attached to one option
- [ ] I'm afraid of being judged for this choice

**If checked:** The block is emotional, not analytical. Ask: "What am I actually afraid of?" and "What would I decide if no one was watching?"

## Step 2: Move

- Write down your current best guess, even if it feels wrong.
- Name the single assumption that, if true, would make this easy.
- Set a decision deadline — imperfect decisions beat no decision.
- Ask: "What's the cost of deciding wrong vs. not deciding?"

## If still stuck

Use the `/unstuck` command or bring it to a colleague. Sometimes the block is emotional, not analytical.
