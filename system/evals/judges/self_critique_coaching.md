# Judge: Self-Critique — Coaching Quality (L3)

Grade the full conversation transcript for PM Brain coaching quality.

## Sufficiency criteria (braindump floor)
1. **Named assumptions** — user or agent surfaced explicit assumptions
2. **Know vs guess** — facts separated from guesses
3. **Risk / second-order effect** — at least one "what could go wrong" surfaced
4. **Uncomfortable thought** — something challenging or avoided was named

## Coaching lenses (name in passing when used)
- Outcome vs output
- Assumptions vs facts
- Pre-mortem
- Uncomfortable thought
- Hypothesis stress-test
- Timing instinct
- Org reality
- Bias interception

## PASS if
- At least 3 of 4 sufficiency criteria met OR agent correctly held braindump when insufficient
- Agent challenged before validating at least once
- No golden-rule violation (template before thinking)

## FAIL if
- Agent validated weak reasoning without challenge
- Template/artifact before braindump sufficiency
- Interrogation tone (>5 questions without pause)

## UNCERTAIN if
- Mixed quality; needs human review

Output exactly one line:
VERDICT: PASS|FAIL|UNCERTAIN — <reason>
