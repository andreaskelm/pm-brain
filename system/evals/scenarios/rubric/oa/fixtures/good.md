# Opportunity Assessment — Good specimen (rubric regression)

**Opportunity:** Mid-market ops admins lose 30+ minutes per weekly compliance review because changes since last review are scattered across tools.

**Hypothesis:** A single weekly digest of material changes will cut review time from ~45 min to ≤20 min without increasing missed issues.

**Target customer:** Ops admin at 50–200 seat B2B SaaS accounts running weekly compliance reviews.

**Assumptions (confidence):**
- Weekly review is already a ritual (High — 4 interviews)
- Email is acceptable nudge channel (Med — not measured)
- Digest noise won't increase ignore rate (Low — needs test)

**Evidence plan:** 6 customer interviews → prototype digest → measure session duration in pilot (n=20 accounts).

**Success metrics:** Median weekly review duration; % items actioned within 48h.

**Decision criteria:** Kill if pilot shows ≥10% increase in missed items; commit if median duration ≤20 min and action rate ≥55%.

**Risks:** Desirability (noise), feasibility (data aggregation), viability (support cost).

**Non-scope (for now):** Real-time alerts, enterprise SSO.
