# Weekly Notes

One file per week: `YYYY-Www.md` (e.g. `2026-W41.md`). Fifteen minutes, ideally Friday.

**The agent drafts it.** Run the weekly review (`/weekly-review`). It reads this week's conversations and work, resolves due rows in [decisions.md](../decisions.md), runs the drift sweep, and drafts the note below. Your job is to correct it and answer the questions it can't answer for you, especially "what am I avoiding?".

Skip weeks when nothing happened. A thin note you actually write beats a rich template you don't.

---

## Template

```markdown
# Week YYYY-Www

## Shipped / moved
[What actually changed in the world this week — not activity.]

## Decisions
New rows in decisions.md this week: [links or "none"]
Resolved: [decision — outcome — surprise]

## Live assumptions
Beliefs you're carrying but haven't decided on. 3–5 max; drop them when decided, disproved, or documented.

| Assumption | Evidence | Last challenged | What would change my mind |
|------------|----------|-----------------|---------------------------|
| | documented / verbal / hunch / industry | YYYY-MM-DD or never | |

## Drift sweep
Anything this week that cuts against a reopen trigger or a live assumption? [one line each, or "nothing"]

## What I learned
[Pattern, surprise, or discomfort. Discomfort usually matters most.]

## What am I avoiding?
[Honest answer.]

## Next week
[One focus. One decision coming up.]
```

Once a month, the weekly review can roll the last four notes into a short synthesis. Template: [monthly synthesis](../../2-Methods/1-Foundations/3-Self-Reflection/3-monthly-synthesis-template.md).
