# Weekly Notes

One file per week: `YYYY-Www.md` (e.g. `2026-W41.md`). Fifteen minutes, ideally Friday.

**The agent drafts it.** Run the weekly review (`/weekly-review`). It reads this week's conversations and work, resolves due rows in [decisions.md](../decisions.md), runs the drift sweep, and drafts a note from [template.md](template.md). Your job is to correct it and answer the questions it can't answer for you, especially "what am I avoiding?".

Skip weeks when nothing happened. A thin note you actually write beats a rich template you don't.

If something from the week is worth telling a manager, offer one update to [showcase.md](../showcase.md) — don't start a second log.

Once a month, roll the last four notes into a short synthesis. Template: [monthly synthesis](../../2-Methods/1-Foundations/3-Self-Reflection/3-monthly-synthesis-template.md). Refresh [showcase.md](../showcase.md) from that pass when a 1:1 or review is coming.
